# LifeLine-ICT Setup Guide

## Backend Setup
1. Clone the repository
2. Create a virtual environment
3. Install dependencies
4. Run the backend server

## IoT Device Instructions
- Connect your sensor to the network
- Update configuration with backend URL
- Run the sensor script to send data

## Directory Structure
- app/ → Backend code
- iot/ → IoT device scripts
- docs/ → Documentation
- frontend/ → Web/mobile dashboards (planned)
- deployment/ → Infrastructure scripts (planned)
